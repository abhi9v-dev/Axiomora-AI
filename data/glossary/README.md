# data/glossary

Reserved for the business glossary, measure definitions, table/column/
relationship documentation and validation-constraint documents that the
Schema Agent chunks, embeds and retrieves (see
[docs/02_SRS_SRD.md](../../docs/02_SRS_SRD.md), FR-001/FR-002).

Populated in Phase 1 (initial documents) and indexed in Phase 2 (chunking,
embedding and pgvector storage).
